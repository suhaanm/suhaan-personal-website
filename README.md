# Suhaan Mobhani - Personal Website

A premium, high-performance personal website built with React, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Features
- **Modern Tech Stack**: React 19, Vite 7, TypeScript.
- **Rich Aesthetics**: Custom animations with GSAP and Lenis for smooth scrolling.
- **Responsive Design**: Fully optimized for all screen sizes.
- **Interactive Elements**: Particle spheres, magnetic buttons, and data stream background effects.
- **SEO Optimized**: Pre-configured meta tags for search engines and social sharing.

## 🛠️ Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/suhaanm/suhaan-personal-website.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 🏗️ Build and Deployment
To create a production build:
```bash
npm run build
```
The output will be in the `dist/` directory, ready to be deployed as a static site (e.g., GitHub Pages, Vercel, Netlify).
